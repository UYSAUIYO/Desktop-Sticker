# Desktop Sticker — 桌面分区收纳 + 搜索启动器 设计文档

日期：2026-08-18
状态：已确认，待用户审阅

## 1. 背景与目标

开发一个 Windows 11 桌面工具，解决两个核心问题：

1. **桌面图标分类收纳**：把杂乱桌面图标收纳进可折叠、可拖拽、可自由调整的“分区”中，保持桌面整洁且美观。
2. **更方便地搜索应用**：通过自定义全局热键（默认双击空格）唤起搜索启动器，快速搜索并打开桌面内容、用户常用目录中的文件，以及用户手动添加的应用。

视觉要求：与 Windows 11 原生 UI 风格保持一致（Fluent / Acrylic / Mica、圆角、细边框、深浅色主题跟随系统），并且“美观前卫”。

## 2. 总体架构

```
DesktopSticker.exe（薄宿主入口）
├── WinUI 3 App 生命周期 / 托盘图标 / 设置窗口
└── 加载 DesktopSticker.Features.dll（唯一功能 DLL）
    ├── DesktopWorkspace 模块 —— 桌面分区收纳
    ├── Launcher 模块 —— 双击空格搜索启动器
    └── Shared 服务
        ├── ConfigStore：JSON 配置读写
        ├── IndexService：索引与搜索
        ├── IconService：图标提取与缓存
        ├── HotkeyService：全局热键（双击空格）
        └── ShellLauncher：ShellExecuteEx 打开/启动
```

### 2.1 EXE 与 DLL 边界

- **EXE 只负责**：应用生命周期、创建 WinUI 3 窗口宿主（设置窗口、启动器窗口）、托盘图标、把 UI 事件转发给 DLL。
- **DLL 只负责**：功能逻辑、状态管理、配置持久化、索引、热键、与 Shell 交互。
- **接口**：EXE 与 DLL 通过稳定的 C++ 接口（`IFeatureModule` + 事件回调）通信，UI 层不直接调用 Shell API。
- 以后可单独替换 DLL 升级功能，EXE 保持稳定。

### 2.2 技术栈

- **主程序**：WinUI 3（C++/WinRT），用于设置窗口与搜索启动器窗口。
- **桌面分区窗口**：原生 Win32 分层窗口 + Direct2D 自绘（原因见 3.1）。
- **构建**：Visual Studio 2022 + Windows App SDK / C++/WinRT。
- **数据持久化**：JSON 文件，原子写入。

## 3. 桌面分区子系统（DesktopWorkspace）

### 3.1 桌面嵌入方式（Wallpaper Engine 式）

采用桌面控件（widget）的成熟实现方式：

- 桌面 Shell 层级：`Progman` → `WorkerW` → `SHELLDLL_DefView` → `SysListView32`（原生桌面图标宿主）。
- 向 `Progman` 发送未文档化消息 `0x052C` 创建 `WorkerW`。
- 将分区窗口 `SetParent` 到 `SHELLDLL_DefView`，并 `SetWindowPos` 置于 `SysListView32` 之上。
- 效果：分区窗口悬浮在原生桌面图标上方，但仍属于桌面层，位于普通应用窗口之下。
- **不使用 WinUI 3 窗口做分区窗口**：WinUI 3 窗口不支持可靠重挂父窗口到桌面 Shell 下，渲染/输入可能异常。
- 多显示器：每个显示器创建独立分区窗口，坐标独立持久化。
- **降级策略**：若 `0x052C` / `SetParent` 嵌入失败，退化为普通置底透明窗口模式，功能不中断。

### 3.2 数据模型

- `Zone`：ID、名称、矩形区域（按显示器）、折叠状态、主题/颜色、排序方式。
- `Item`：被收纳的 Shell 项（快捷方式/文件/文件夹）、所属 Zone ID、来源（自动/手动）。
- `NativeIconState`：被收纳原生图标的原始坐标记录（用于移出可视区和恢复）。

### 3.3 收纳机制

- **首次运行**：枚举 `SysListView32` 中的桌面图标，按类型自动分类（应用/文档/图片/文件夹/游戏等），创建分区。
- **收纳动作**：将对应原生图标用 `LVM_SETITEMPOSITION` 移到屏幕外（如 `-32000,-32000`），同时在分区内绘制自绘磁贴。原生桌面不再重复显示。
- **自动排列处理**：若系统开启“自动排列图标”，需要先临时关闭（或采用等效方案），避免被收纳图标被系统自动移回可视区域；恢复桌面时还原原设置。
- **取消收纳**：原生图标移回记录的原始坐标，移除分区内磁贴。
- **新图标监听**：使用 `ReadDirectoryChangesW` 监听桌面目录 + 监听 ListView 变化；新图标按规则自动归类，或留在原生桌面等待用户拖入。

### 3.4 交互

- 点击分区标题栏：折叠 / 展开（折叠时磁贴隐藏，原生图标保持屏幕外）。
- 分区内磁贴拖到另一分区：更新 Zone 归属。
- 原生图标拖入分区（或右键“收纳到分区”）：分区窗口实现 `IDropTarget` 接收 Shell 拖放项，收纳该图标。
- 磁贴右键菜单：打开 / 从分区移出 / 固定回桌面。
- 分区标题右键菜单：重命名 / 新建 / 删除分区。
- 双击桌面空白：通过子类化 `SysListView32` 监听原生桌面空白处的双击，并支持双击分区窗口空白处，两者都触发“干净桌面”切换（隐藏 / 恢复所有分区和原生图标）。
- 标题栏拖动移动分区，边缘拖拽调整大小。

### 3.5 渲染与启动

- Direct2D 绘制 Win11 风格：Acrylic 半透明、圆角、细边框、深浅色主题跟随系统。
- 图标用 `IShellItemImageFactory` / `SHGetFileInfo` 提取高清图标，`IconService` 缓存。
- 打开/启动用 `ShellExecuteEx`；右键菜单优先调用 Shell 原生 `IContextMenu`。

### 3.6 安全与还原

- 一键“恢复系统桌面”：所有原生图标移回原坐标、移除分区窗口、清空自绘磁贴。
- 布局配置实时持久化，崩溃/重启可恢复。
- 技术风险：`0x052C`/`SetParent` 依赖未文档化 Shell 行为，Win11 大版本更新可能变化；已有降级方案兜底。

## 4. 搜索启动器子系统（Launcher）

### 4.1 唤起方式：双击空格

- `HotkeyService` 使用低级键盘钩子 `WH_KEYBOARD_LL` 检测双击空格：两次按下间隔 ≤ 250ms 且中间有释放。
- **防误触**：若前台焦点在文本输入框（记事本、浏览器地址栏、聊天框等），不触发。
- 默认双击空格，设置中可更换为任意组合键（如 `Alt+Space`）。

### 4.2 索引范围与构建

`IndexService`：

- **数据源**：
  1. 桌面目录全部项目；
  2. 用户常用目录：文档 / 下载 / 图片 / 视频 / 音乐（`SHGetKnownFolderPath`）；
  3. 用户手动添加的应用列表（配置存储，不自动扫描全盘）。
- **索引方式**：启动时后台扫描建立内存索引；`ReadDirectoryChangesW` 实时监听，增量更新。
- **排除项**：隐藏文件和系统文件默认跳过（可配置）。
- **中文搜索增强**：扫描时为文件名生成拼音首字母索引，支持输入“wx”搜到“微信”。

### 4.3 启动器 UI（WinUI 3）

- 无边框窗口，屏幕顶部居中弹出；Acrylic 毛玻璃、圆角、细边框，跟随系统主题。
- 顶部搜索输入框 + 下方结果列表（图标 + 名称 + 路径）。
- 交互：
  - 双击空格：已打开则关闭，未打开则弹出并聚焦输入框；
  - 实时搜索（防抖 ~100ms），结果按来源分组（应用 / 桌面 / 文档 / 下载 / 图片 / 视频 / 音乐）；
  - `↑`/`↓` 选择，`Enter` 打开（`ShellExecuteEx`），`Esc` 关闭；
  - 结果项右键：打开所在文件夹 / 固定到应用列表。
- 窗口特性：`WS_EX_TOOLWINDOW` 不进任务栏，打开时置顶激活，关闭后不驻留。

### 4.4 与桌面分区联动

- 分区收纳不影响索引：被收纳图标仍在桌面目录（原生图标移出可视区），搜索照常命中。
- 用户手动添加的应用与分区磁贴共用 `IconService` 缓存，打开逻辑统一走 `ShellLauncher`。

## 5. 配置持久化

统一存放 `%APPDATA%\DesktopSticker\`：

| 文件 | 内容 |
|---|---|
| `config.json` | 全局设置：热键方案、主题、搜索范围、排除项 |
| `layout.json` | 分区布局：Zone 列表、坐标、折叠状态、Item 归属、原生图标坐标记录 |
| `apps.json` | 用户手动添加的应用列表 |
| `cache/` | 图标缓存 |
| `logs/` | 运行日志 |

- 原子写入：先写临时文件再替换。
- 启动加载、变更防抖保存；损坏时自动备份 `.bak` 并重建默认配置。

## 6. 错误处理与降级

- **Shell 嵌入失败**：退化为普通置底透明窗口模式，并提示用户。
- **图标提取失败**：使用通用默认图标占位。
- **无权限/占用文件**：跳过并写日志。
- **崩溃恢复**：启动时校验配置，损坏则 `.bak` 恢复或重建。
- **一键还原**：所有原生图标移回原始坐标、移除分区窗口、恢复系统桌面原状。

## 7. 测试策略

- **单元测试**（C++/WinRT）：
  - `ConfigStore` 读写与损坏恢复；
  - `IndexService` 文件名匹配、拼音首字母匹配、排除规则；
  - `HotkeyService` 双击判定（注入时间源，测间隔阈值与文本输入防误触）；
  - `Zone` 数据模型：收纳/取消收纳状态转换。
- **集成测试**：在真实 Windows 11 上验证 `WorkerW` 嵌入、原生图标移出/恢复、拖拽换分区、多显示器布局。
- **手动验收清单**：首次启动自动分类 → 拖拽/折叠/双击隐藏 → 搜索命中与打开 → 恢复桌面 → 多显示器。

## 8. 范围与后续

**MVP 范围**：

- 桌面分区：首次自动分类、手动调整、折叠/展开、拖拽换分区、右键归类、自由调整大小/位置、双击隐藏、一键还原。
- 搜索启动器：双击空格唤起、搜索桌面 + 常用用户目录 + 手动添加应用、中文拼音首字母、Enter 打开。
- 设置窗口：热键配置、主题、搜索目录/排除项、应用列表管理。

**暂不包含**：

- 自动扫描全盘已安装应用（改为用户手动添加）。
- 全盘文件索引（Everything 式）。
- 网页/书签搜索。
