# Desktop Sticker 验收清单

> 使用方式：手动运行程序后逐项验证，每项完成后勾选。
> 程序启动前请确认 `DesktopSticker.Features.dll` 已位于 EXE 同目录（Release 构建会自动复制，见工程 PostBuildEvent）。

## 动态桌面壁纸

准备：先运行 `tools/prepare_ffmpeg.ps1` 取回固定版本负载（不入版本库）。

- [ ] 壁纸显示在**原生桌面图标之下**，且分区卡片在壁纸**之上**
- [ ] 桌面图标仍可点击与双击打开；双击桌面空白仍能切换干净桌面（壁纸窗口未截获双击）
- [ ] 导入视频后自动启用并循环播放；源文件字节与导入前一致（比对 hash）
- [ ] 日志 `[wallpaper]` 显示实际解码路径；普通素材走 Media Foundation，MF 不支持的素材回落 FFmpeg
- [ ] 后台生成 `variants\balanced-v1.mp4` 与 `poster.png`；删除/重建副本后**源文件仍不变**
- [ ] 全屏应用切进切出 → 暂停/恢复；`Win+L` 锁屏 → 停止，解锁 → 恢复；手动暂停生效
- [ ] 存储根落在剩余空间最大的**固定盘**（可移动盘/网络盘不被选中）；`wallpaper.json` 记录卷序列号与根文件 ID
- [ ] 拔掉/改盘符使库根失效后：壁纸降级为不可用，其余功能正常，且不向未验证路径写入
- [ ] 把 `DesktopSticker.WallPaper.dll` 改名：分区/搜索/时钟完全正常（壁纸卡片显示不可用）
- [ ] 移除 `tools/ffmpeg\`：原画（MF）仍可播放，仅副本生成与 FFmpeg 兜底不可用
- [ ] 分区拖拽/滚轮/双击、时钟、设置页既有项全部无回归
- [ ] 退出后无游离窗口，桌面图标与分区正常还原
- [ ] 1080p 与 4K 各跑一段（H.264/HEVC），记录 CPU、GPU Video Decode、工作集、句柄数

### ② 动图与图片序列

- [ ] 导入 `.gif` / 动态 `.webp`：能动画播放，且**逐帧延迟正确**（日志解码路径应为 FFmpeg，
      MF 只能出首帧所以动图刻意优先 FFmpeg）
- [ ] 「导入文件夹…」选一个纯图片目录 → 记为「图片序列」，按**自然序**播放（`img2` 在 `img10` 前）
- [ ] 序列默认 100ms/帧（10fps）；播放速度档位能改变节奏
- [ ] 源文件夹逐字节未改动（比对 hash）；目录里的非图片文件被跳过并计入日志
- [ ] 「导入文件夹…」选一个没有可识别内容的目录 → 明确报错，不产生半截条目

### ③ Web 壁纸

- [ ] 「导入文件夹…」选含 `index.html` 的目录 → 记为「网页」，桌面显示页面内容
- [ ] 页面显示在桌面图标与分区卡片**之下**；点页面区域不抢焦点、不影响分区拖拽/双击
- [ ] 带透明背景的页面：透明处露出**原始桌面壁纸**
- [ ] 暂停（全屏/锁屏/手动）→ 页面停住；恢复后继续（`TrySuspend` / `Resume`）
- [ ] 网页类型的「播放速度」置灰；「播放声音」可用而音量滑块置灰（页面音量不归我们管）
- [ ] 从网页切回视频/序列再切回网页：**不黑屏、不互相遮盖**（视觉宿主的换根/还原）
- [ ] 卸载 Edge WebView2 Runtime 后：③ 不可用，其余后端与分区/时钟正常
- [ ] 视频帧率自检：日志 `fps diag` 的 `frames=` 应贴近源帧率（4K/30fps 源应 ≥28/s），
      `size=` 应等于窗口尺寸而不是源尺寸（说明按显示尺寸解码生效）

### ④ 3D / 着色器（阶段 0）

准备：`tools/prepare_vulkan.ps1` + `tools/prepare_shaderc.ps1`（只影响构建与工具链，运行只需要显卡驱动自带的 `vulkan-1.dll`）。

- [ ] 导入一个含 `.frag` 的目录 → 记为「3D / 着色器」，桌面显示**内置全屏着色器**（彩色等离子）
- [ ] 着色器画面在桌面图标、分区卡片、时钟**之下**；图标仍可点击、双击空白仍能切换干净桌面
- [ ] 日志 `fps diag` 的 `frames=` 与 `vulkan diag` 的 `ticks=` 都贴近 **60/s**（vsync 锁定）
- [ ] `vulkan diag` 里 `acquire` / `present` 都是几十微秒量级（说明时间没花在 Vulkan 调用上）
- [ ] 从着色器切回视频/序列再切回着色器：不黑屏、不互相遮盖
- [ ] 暂停（全屏/锁屏/手动）时画面停住；恢复后继续
- [ ] 临时把 `tools/vulkan-sdk` 改名后重新编译：**编译仍通过**，④ 降级为不可用，其余后端与功能区正常
- [ ] 缺 Vulkan 设备（例如只在虚拟机里）时不崩溃：④ 不可用，进程照常运行

## 资源管理器

准备：需要 WebView2 运行时（Win11 通常已预装）。

- [ ] 托盘菜单出现"资源管理器"；也可用 `--resmon` 启动参数直接打开
- [ ] CPU 页每 2s 刷新，数值随负载变化；**线程名可读**（至少能看到"UI / 分区渲染""壁纸渲染与帧调度"）
- [ ] 触发一次壁纸转码（导入较大视频）→ CPU 页出现 `ffmpeg.exe` 子进程项
- [ ] 内存页列出模块映像大小并降序；**只出现本程序自己的模块**（exe + 三个功能 DLL + ffmpeg 的 av*/sw*.dll），不得出现 SHELL32 / nvgpucomp64 / Microsoft.UI.Xaml / DirectML 等系统或第三方 DLL；总量与任务管理器同量级
- [ ] 存储页"重新计算"后：壁纸媒体库 ≈ 351 MB、FFmpeg 负载 ≈ 157 MB、调试符号 ≈ 71 MB；**各分类占比合计恰为 100.0%**；合计等于各分类之和
- [ ] 存储页把某分类目录改名制造缺失 → 出现 warnings 且页面不崩、不白屏
- [ ] 关闭窗口后重开正常（窗口销毁后重建）；关闭后无残留窗口
- [ ] 把 `DesktopSticker.ResMon.dll` 改名 → 托盘项置灰，分区/搜索/时钟/壁纸全部正常
- [ ] 资源管理器不影响其它功能：分区拖拽/滚轮/双击、搜索启动器、桌面时钟、动态壁纸均无回归
