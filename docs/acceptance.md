## 动态桌面壁纸

准备：先运行 `tools/prepare_ffmpeg.ps1` 取回固定版本负载（不入版本库）。

- [ ] 壁纸显示在**原生桌面图标之下**，且分区卡片在壁纸**之上**
- [ ] 桌面图标仍可点击与双击打开；双击桌面空白仍能切换干净桌面（壁纸窗口未截获双击）
- [ ] 导入视频后自动启用并循环播放；源文件字节与导入前一致（比对 hash）
- [ ] 日志 `[wallpaper]` 显示实际解码路径；普通素材走 Media Foundation，MF 不支持的素材回落 FFmpeg
- [ ] 后台生成 `variants\balanced-v1.mp4` 与 `poster.png`；删除/重建副本后**源文件仍不变**
- [ ] 全屏应用切进切出 → 暂停/恢复；`Win+L` 锁屏 → 停止，解锁 → 恢复；手动暂停生效
- [ ] 存储根落在剩余空间最大的**固定盘**（可移动盘/网络盘不被选中）；`wallpaper.json` 记录卷序列号与根文件 ID
- [ ] 拔掉/改盘符使库根失效后：壁纸降级为不可用，其余功能正常，且不向未验证路径写入
- [ ] 把 `DesktopSticker.WallPaper.dll` 改名：分区/搜索/时钟完全正常（壁纸卡片显示不可用）
- [ ] 移除 `tools/ffmpeg\`：原画（MF）仍可播放，仅副本生成与 FFmpeg 兜底不可用
- [ ] 分区拖拽/滚轮/双击、时钟、设置页既有项全部无回归
- [ ] 退出后无游离窗口，桌面图标与分区正常还原
- [ ] 1080p 与 4K 各跑一段（H.264/HEVC），记录 CPU、GPU Video Decode、工作集、句柄数

### ② 动图与图片序列

- [ ] 导入 `.gif` / 动态 `.webp`：能动画播放，且**逐帧延迟正确**（日志解码路径应为 FFmpeg，
      MF 只能出首帧所以动图刻意优先 FFmpeg）
- [ ] 「导入文件夹…」选一个纯图片目录 → 记为「图片序列」，按**自然序**播放（`img2` 在 `img10` 前）
- [ ] 序列默认 100ms/帧（10fps）；播放速度档位能改变节奏
- [ ] 源文件夹逐字节未改动（比对 hash）；目录里的非图片文件被跳过并计入日志
- [ ] 「导入文件夹…」选一个没有可识别内容的目录 → 明确报错，不产生半截条目

### ③ Web 壁纸

- [ ] 「导入文件夹…」选含 `index.html` 的目录 → 记为「网页」，桌面显示页面内容
- [ ] 页面显示在桌面图标与分区卡片**之下**；点页面区域不抢焦点、不影响分区拖拽/双击
- [ ] 带透明背景的页面：透明处露出**原始桌面壁纸**
- [ ] 暂停（全屏/锁屏/手动）→ 页面停住；恢复后继续（`TrySuspend` / `Resume`）
- [ ] 网页类型的「播放速度」置灰；「播放声音」可用而音量滑块置灰（页面音量不归我们管）
- [ ] 从网页切回视频/序列再切回网页：**不黑屏、不互相遮盖**（视觉宿主的换根/还原）
- [ ] 卸载 Edge WebView2 Runtime 后：③ 不可用，其余后端与分区/时钟正常
- [ ] 视频帧率自检：日志 `fps diag` 的 `frames=` 应贴近源帧率（4K/30fps 源应 ≥28/s），
      `size=` 应等于窗口尺寸而不是源尺寸（说明按显示尺寸解码生效）

### ④ 3D / 着色器

准备：`tools/prepare_vulkan.ps1` + `tools/prepare_shaderc.ps1`（只影响构建与工具链，运行只需要显卡驱动自带的 `vulkan-1.dll`）。

- [ ] 导入一个含 `.frag` 的目录 → 记为「3D / 着色器」，桌面显示**内置全屏着色器**（彩色等离子）
- [ ] 导入一个只含 `scene.json`（`{"scene":"model"}`）的目录 → 桌面显示**内置 32 面体**：
      12 个五边形 + 20 个六边形、每个面一种配色、有明暗与高光，缓慢自转 + 环绕相机
- [ ] 32 面体不超出屏幕（相机距离足够）；日志有 `vulkan: built-in model ready, 116 triangles, 32 faces`
- [ ] 着色器画面在桌面图标、分区卡片、时钟**之下**；图标仍可点击、双击空白仍能切换干净桌面
- [ ] 日志 `fps diag` 的 `frames=` 与 `vulkan diag` 的 `ticks=` 都贴近 **60/s**（vsync 锁定）
- [ ] `vulkan diag` 里 `acquire` / `present` 都是几十微秒量级（说明时间没花在 Vulkan 调用上）
- [ ] 从着色器切回视频/序列再切回着色器：不黑屏、不互相遮盖
- [ ] 暂停（全屏/锁屏/手动）时画面停住；恢复后继续
- [ ] 临时把 `tools/vulkan-sdk` 改名后重新编译：**编译仍通过**，④ 降级为不可用，其余后端与功能区正常
- [ ] 缺 Vulkan 设备（例如只在虚拟机里）时不崩溃：④ 不可用，进程照常运行

## 资源管理器

准备：需要 WebView2 运行时（Win11 通常已预装）。

- [ ] 托盘菜单出现"资源管理器"；也可用 `--resmon` 启动参数直接打开
- [ ] CPU 页每 2s 刷新，数值随负载变化；**线程名可读**（至少能看到"UI / 分区渲染""壁纸渲染与帧调度"）
- [ ] 触发一次壁纸转码（导入较大视频）→ CPU 页出现 `ffmpeg.exe` 子进程项
- [ ] 内存页列出模块映像大小并降序；**只出现本程序自己的模块**（exe + 三个功能 DLL + ffmpeg 的 av*/sw*.dll），不得出现 SHELL32 / nvgpucomp64 / Microsoft.UI.Xaml / DirectML 等系统或第三方 DLL；总量与任务管理器同量级
- [ ] 存储页"重新计算"后：壁纸媒体库 ≈ 351 MB、FFmpeg 负载 ≈ 157 MB、调试符号 ≈ 71 MB；**各分类占比合计恰为 100.0%**；合计等于各分类之和
- [ ] 存储页把某分类目录改名制造缺失 → 出现 warnings 且页面不崩、不白屏
- [ ] 关闭窗口后重开正常（窗口销毁后重建）；关闭后无残留窗口
- [ ] 把 `DesktopSticker.ResMon.dll` 改名 → 托盘项置灰，分区/搜索/时钟/壁纸全部正常
- [ ] 资源管理器不影响其它功能：分区拖拽/滚轮/双击、搜索启动器、桌面时钟、动态壁纸均无回归

## 交互壁纸（场景 / 网页）

准备：设置页「桌面壁纸 → 鼠标与键盘交互」开关打开（默认开）；当前壁纸是 `.dswall` 场景包或网页壁纸。

- [ ] 鼠标移动到壁纸上：场景/页面能收到**移动**（悬停效果跟随，不闪、不抽）
- [ ] **按住左键拖动**：被拖动对象/相机连续跟手，没有"抽搐 / 回跳"；拖出壁纸区域（压到分区卡片、
      任务栏、副屏）时拖动仍然连续，松手后正常结束
- [ ] 单击、双击、右键、滚轮各一次：页面/场景按预期响应；桌面上**不出现选择框、不弹右键菜单**
- [ ] 松开鼠标后不再有"一直按着"的残留（再移动时对象不跟手）
- [ ] 光标在图标/分区卡片上时点击仍归它们（图标能打开、分区能拖/滚）
- [ ] 关掉「鼠标与键盘交互」开关：壁纸立刻不再响应鼠标与键盘，桌面恢复"双击空白切换干净桌面"
- [ ] 开着「鼠标与键盘交互」时：双击桌面空白不再切换干净桌面（壁纸吃掉了点击，属预期）
- [ ] 切到视频壁纸再切回交互壁纸：无残留捕获、无黑屏
- [ ] 日志无 `SendMouseInput failed` / `SetWindowsHookExW failed`；`mouse relay: 5s …` 里
      `leaves` 为 0（除非光标离开壁纸区域）、`rejected` 接近 0

### 键盘（仅场景壁纸）

> 推荐用仓库自带的 `samples/3d-keyboard-test.dswall`（「3D 键盘 / 鼠标测试台」，源工程在
> `samples/keyboard-test-src/`，重建方法见 `samples/README.md`）：键帽实时高亮、HUD 显示按下/松开计数、
> 滚轮与拖动距离，单键、组合键、左/右/中键、滚轮、拖动一次看全。

- [ ] 在空白桌面**单击**一下：前台切到桌面（`Progman`）、任务栏不出现新窗口；随后的按键才转发进壁纸
      （键盘只在"桌面是前台"时转发，这是必要条件）
- [ ] 在空白桌面**单击**一下，然后按方向键 / `WASD` / 空格：场景壁纸收到按键（`Input.is_key_pressed` 生效）
- [ ] **组合键**：按住 `Shift`+`W`+`A` 之类多键同时按，场景里每个键都保持"按下"（不是只认最后一个）
- [ ] 按 `Shift`、`Ctrl`、`Alt` 组合键：场景能识别修饰键（不是只收到裸键）
- [ ] 按住某键不放：场景收到**重复按下**（echo 标记为真），不会连成乱码
- [ ] 正常打字（中文输入法开着）：**壁纸上不弹候选窗**（转发的键已吞掉），输入法只在别的应用里工作
- [ ] 点击别的应用（记事本/浏览器）后再按键：按键回到那个应用，壁纸**不再截获**（看前台是不是桌面）
- [ ] 桌面是前台时按 `Win`、`Alt+Tab`、`Ctrl+Shift+Esc`：系统功能照常（这些组合不吞）
- [ ] 日志 `mouse relay: 5s … keys=N` 的 N 随按键增长；`key relay: fg is not desktop` 只在
      前台不是桌面时出现（此时不转发，属预期）。`godot host: keyboard focus failed` 是**已知且无害**的：
      挂在 WorkerW 下的窗口拿不到焦点（Windows 返回 87），键盘由钩子转发兜底
- [ ] 切到视频壁纸（引擎窗口隐藏）后按键：键盘完全还给系统，无截获
- [ ] 网页壁纸不参与键盘：点击网页区域后按键仍归属当前前台应用（预期内限制）

## 2D 壁纸编辑器（Studio）

### 时间轴

- [ ] 新建工程 → 加一个文字图层 → 选中它：底部时间轴出现 5 条通道（X / Y / 缩放 / 旋转 / 不透明度）
- [ ] 播放头拖到 0，点 X 的「＋」；拖到 2s，把画布上的文字往右拖 200px：轨道上多出关键帧（自动关键帧）
- [ ] 点「播放」：文字从左往右匀速移动，时间读数滚动；再点一次暂停，画面停在当前位置
- [ ] 拖播放头：选区框和元素一起走（框不会留在原地）
- [ ] 拖播放头时属性面板的 X / Y / 旋转 / 不透明度数字跟着变（播放中也在变）；
      改这些数字会写进当前帧，而不是改一个播放时被覆盖的基础值
- [ ] 选中没有动画的图层：属性面板显示基础值，改数字仍是普通的静态修改
- [ ] 属性面板的「缩放」改大：时间轴上自动出现 scale 轨道，元素在画布上真的变大
- [ ] 拖动关键帧改时间（0.05s 吸附）；右键删除；双击轨道空白插入关键帧
- [ ] 时间轴「时长」改成 4s：播放到 4s 回到 0（关键帧都在 4s 以内时）
- [ ] 把时长改到末帧之前：超出段被压暗、关键帧标红，状态栏提示「N 个关键帧超出时长」，
      导出被校验拦住；点「适配末帧」后时长回到末帧、提示消失、可以导出
- [ ] 把画布从 1080p 换成 4K（属性面板的预设）：动画元素的位置与运动幅度按比例放大，
      关键帧一个都没变；再换回来，画面与换之前一致
- [ ] 画布预设逐档选一遍（1080p / 2K / 4K / 竖屏 / 方形）：左上角尺寸与所选档位一致
      （旧版本整体错位一格，选 1080p 得到 2K）
- [ ] 时间轴标尺上非整数秒的刻度有标签（0.5s / 1.5s），控制台没有
      `unsupported format character` 刷屏
- [ ] 把有动画的图层「放进容器」再「移出容器」：画面不跳，动画的运动幅度随容器大小缩放
- [ ] 打开一个 `format_version: 1` 的旧工程（像素关键帧）：动画位置与升级前一致
- [ ] 导出一段带缓动（JSON 里 `"ease": "in"`）的动画并应用：桌面上是缓入，不是匀速；
      同一段在编辑器预览里拖播放头，画面与桌面一致
- [ ] 做一个首尾数值不同的动画：状态栏提示「循环接缝会跳」；点「闭合循环」后提示消失，
      播放到末端回到开头时不再跳，时间轴终点多出一个关键帧
- [ ] 加一个遮罩层并选中：时间轴只显示「效果层暂不支持关键帧」，不出现通道行
- [ ] 导出并应用到桌面：桌面上元素真的在动；重新打开工程，关键帧还在
